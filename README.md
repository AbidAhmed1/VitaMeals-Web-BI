# VitaMeals — Hospital Catering & BI System

## 🛍️ Overview
**VitaMeals** is a full-stack web and decision-support solution designed to manage and streamline catering operations in hospitals and clinics.

The project was developed as a Year-End Project (**PFA - Projet de Fin d'Études**) at **ESEN Manouba**.

## 🚀 Features
* 🏥 **Patient & Diet Tracking** — Precise management of dietary restrictions assigned by medical staff.
* 👨‍🍳 **Kitchen Management** — Meal preparation workflows and distribution tracking.
* 📊 **Business Intelligence & Reporting** — Decision-support analytics for meal distribution and cost optimization.

## 🛠️ Technologies
* **Backend:** PHP
* **Frontend:** JavaScript, HTML5, CSS3
* **Database:** MySQL
* **BI & Analytics:** Power BI (Data Modeling & Dashboard Design)

## 🎯 Project Objective
To eliminate food management errors in healthcare facilities and empower administrators with actionable data insights.

> **Note on BI Assets:** The core web application source code and MySQL database script are fully available in this repository. The standalone `.pbix` Power BI source file is archived separately.
